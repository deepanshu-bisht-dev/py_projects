## 🗂️ Projects

| # | Project | Description | Concepts / Libraries |
|---|---------|-------------|------------------------|
| 01 | [Simple Calculator](./01%20Simple%20Calculator) | A terminal-based calculator that performs addition, subtraction, multiplication, and division based on user input. | `match-case`, exception handling |
| 02 | [Question & Answers Game](./02%20Question%20%26%20Answers%20Game) | A KBC ("Who Wants to Be a Millionaire")-style quiz game with 16 trivia questions on Indian geopolitics and an escalating prize ladder. | Lists, loops, custom data structures |
| 03 | [PDF Merger](./03%20Pdf%20Merger) | Merges multiple PDF files into a single document based on user-provided file names. | `PyPDF2` |
| 04 | [News App](./04%20News%20App) | Fetches the latest news articles on a user-specified topic using the NewsAPI. | `requests`, REST APIs, JSON parsing |
| 05 | [Drink Water Reminder](./05%20Drink%20Water%20Reminder) | A background utility that sends a desktop notification every hour as a reminder to drink water. | `plyer`, `time`, infinite loops |

> Each project folder includes its own `main.py`, and some include an `explanation.txt` with a line-by-line breakdown of the code.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/deepanshu-bisht-dev/py_projects.git
cd py_projects
```

Navigate into any project folder and run it:

```bash
cd "01 Simple Calculator"
python main.py
```

Some projects need extra packages — install them as needed:

```bash
pip install PyPDF2      # for PDF Merger
pip install requests    # for News App
pip install plyer       # for Drink Water Reminder
```
